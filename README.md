
# Breast Cancer Detection with Explainable AI (XAI)

**Project documentation in progress.**

## Overview

This repository contains Colab notebooks developed as part of my research on **integrating interpretability into deep learning models for mammogram-based breast cancer detection**.

The project explores the use of deep learning for breast cancer detection and investigates Explainable AI (XAI) techniques to better understand how models arrive at their predictions. The goal is to improve model transparency and interpretability, particularly in a healthcare context where understanding AI-driven predictions is important.

## Published Research

This project contributed to the following IEEE conference publication:

## Research Objectives

- Explore deep learning approaches for mammogram-based breast cancer detection.
- Investigate Explainable AI techniques to interpret model predictions.
- Examine how visual explanations can help identify image regions influencing model predictions.
- Evaluate the challenges of developing interpretable deep learning models for medical imaging.

## Technologies and Methods

- **Programming Language:** Python
- **Deep Learning:** Convolutional Neural Networks (CNNs)
- **Explainable AI:** SHAP-based explanation methods, including DeepSHAP and PartitionSHAP
- **Data Science:** Image preprocessing, data augmentation, model training, and evaluation
- **Libraries:** TensorFlow and relevant Python data science and visualization libraries
